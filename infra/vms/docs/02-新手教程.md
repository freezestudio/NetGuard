# 新手教程：用这两台虚拟机做驱动开发

面向"没接触过 Hyper-V / 没写过驱动"的人。跟着做就能跑通第一个驱动。

---

## 1. 先搞清三件事

| 名词 | 一句话解释 |
|---|---|
| **Hyper-V** | Windows 自带的虚拟机软件，已经开好了。两台虚拟机就躺在里面 |
| **testsigning（测试签名）** | 让 Windows 允许加载"自己签的、微软不认的"驱动。**不开就装不上你自己的驱动**（会报"数字签名无法验证"） |
| **内核调试** | 把驱动运行在虚拟机里，出问题时从宿主用 WinDbg 抓现场。已配好串口管道 |

两台虚拟机都已经：开好 testsigning、开好内核调试、账户 `freeze` / `1`。

---

## 2. 打开虚拟机

双击 `infra\vms\启动Win10.cmd`（或 `启动Win7.cmd`）。

- 会弹出一个虚拟机窗口（VMConnect）
- Win10 会自动登录到桌面；Win7 停在登录界面，输入 `freeze` / `1`
- 关虚拟机：在**虚拟机内部**点开始菜单 →「关机」。不要直接关窗口（关窗口只是关掉"显示器"）

窗口里的小技巧：

- `Ctrl+Alt+End` = 代替 `Ctrl+Alt+Del`
- 顶部工具栏可以「增强会话」（更好画质/剪贴板/盘符重定向），Win10 支持，Win7 建议直接用 RDP
- 全屏：`Ctrl+Alt+Break`

**Win10 还可以直接用远程桌面连**（更流畅）：
`mstsc /v:172.30.18.120`，账户 `freeze` / `1`

---

## 3. 在宿主上准备编译环境（一次就好）

驱动要在**宿主**编译，虚拟机只当"测试机"。

1. 装 **Visual Studio 2022**（社区版即可，安装时勾选「使用 C++ 的桌面开发」）
2. 装 **Windows Driver Kit (WDK)**：<https://learn.microsoft.com/windows-hardware/drivers/download-the-wdk>
   - 先装 VS2022 的 C++ 工作负载，再装 WDK（WDK 会检查 VS 环境）
3. 装 **WinDbg**：`winget install Microsoft.WinDbg`
4. （可选）装 Windows SDK 对应版本

> 如果只是调老 Win7 驱动：VS2022 + WDK 也可以把「目标操作系统版本」设成 Windows 7（KMDF 1.9）。
> 极老的项目才需要 VS2010 + WDK 7.1.1。

## 4. 第一个驱动：Hello 内核驱动

### 4.1 建工程
VS2022 →「创建新项目」→ 搜 **Driver** → 选 **Kernel Mode Driver (KMDF)** → 名字 `HelloDriver`。
（如果只看到 "Empty WDM Driver" 也可以，后面自己加代码。）

### 4.2 关键工程设置
- 右键项目 → 属性 →「Driver Settings」
  - **Target OS Version**：`Windows 10`（要支持 Win7 就选 `Windows 7`）
  - **Target Platform**：`Desktop`
- 配置改成 `Debug` + `x64`

### 4.3 改代码
把生成的 `Driver.c`（或你自己加的文件）替换成最小示例：

```c
#include <ntddk.h>

VOID Unload(IN PDRIVER_OBJECT DriverObject)
{
    UNREFERENCED_PARAMETER(DriverObject);
    DbgPrint("[HelloDriver] unloaded\n");
}

NTSTATUS DriverEntry(IN PDRIVER_OBJECT DriverObject, IN PUNICODE_STRING RegistryPath)
{
    UNREFERENCED_PARAMETER(RegistryPath);
    DriverObject->DriverUnload = Unload;
    DbgPrint("[HelloDriver] loaded! OS build = %d\n", NtBuildNumber);
    return STATUS_SUCCESS;
}
```

`DbgPrint` 的输出**只有调试器能看到**（不会进事件日志），所以下一步必须连调试器。

### 4.4 编译
「生成」→ 输出 `HelloDriver.sys`（一般在 `x64\Debug\HelloDriver\`）。

## 5. 把驱动送进虚拟机并加载

### 5.1 Win10（最方便：PowerShell Direct，不需要网络）

在宿主**管理员** PowerShell：

```powershell
$cred = Get-Credential freeze            # 输入密码 1

# 建一个到虚拟机的会话（不走网络，走 VMBus）
$s = New-PSSession -VMName 'Win10-Pro-22H2' -Credential $cred

# 拷文件进去
Copy-Item .\x64\Debug\HelloDriver\HelloDriver.sys -ToSession $s -Destination C:\
Copy-Item .\x64\Debug\HelloDriver\HelloDriver.inf -ToSession $s -Destination C:\   # 如果你有 inf

# 在虚拟机里执行命令
Invoke-Command -Session $s -ScriptBlock { whoami; Get-ComputerInfo | Select OsName, OsVersion }

# 注册并启动驱动（KMDF 驱动可以直接 sc 加载）
Invoke-Command -Session $s -ScriptBlock {
    sc.exe create HelloDriver type= kernel start= demand binPath= C:\HelloDriver.sys
    sc.exe start HelloDriver
    sc.exe query HelloDriver
}
# 卸载
Invoke-Command -Session $s -ScriptBlock { sc.exe stop HelloDriver; sc.exe delete HelloDriver }
```

> 没有 `.inf` 的纯软件驱动，`sc create/start` 就够了。
> 有 `.inf`（真实设备驱动）用：`pnputil /add-driver C:\xxx.inf /install`

### 5.2 Win7（没有 PowerShell Direct）

三条路，任选：
1. **RDP + 盘符重定向**：`mstsc` 连上后在「本地资源 → 详细信息 → 驱动器」勾上，把编译输出目录共享给虚拟机
2. **挂一块盘**：宿主建个小 VHDX，把驱动拷进去，虚拟机里「设置 → SCSI/IDE → 添加硬盘」，然后在虚拟机里复制出来
3. **开共享**：虚拟机里 `ipconfig` 查到 IP，宿主 `net use \\<IP>\C$ /user:freeze 1`，然后 `copy`

之后在虚拟机里同样是 `sc create` / `sc start`。

## 6. 连内核调试器（看 DbgPrint、抓蓝屏）

1. **先别开虚拟机**（或先连接调试器，它需要抢占串口）
2. 宿主 PowerShell 运行：

```powershell
windbg -k com:pipe,port=\\.\pipe\win10dbg,resets=0,reconnect
```
Win7 用 `\\.\pipe\win7dbg`。

3. 出现 `Waiting to reconnect...` 后，再启动虚拟机（或重启它）
4. 连接成功后：

```text
0: kd> .sympath srv*C:\Symbols*https://msdl.microsoft.com/download/symbols
0: kd> .reload
0: kd> g                  ← 放行，让系统继续跑
```
然后你在虚拟机里 `sc start HelloDriver`，就能看到：
```text
[HelloDriver] loaded! OS build = 19045
```

常用命令速查：

| 命令 | 作用 |
|---|---|
| `g` | 继续运行 |
| `Ctrl+Break`（WinDbg 里点 Break） | 中断，回到调试器 |
| `!analyze -v` | **蓝屏后必用**，自动分析原因 |
| `lm` | 列出已加载模块（找你的驱动） |
| `bp HelloDriver!DriverEntry` | 在函数上打断点 |
| `db <addr>` / `dq <addr>` | 看内存 |
| `.reload /f HelloDriver.sys` | 重新加载符号 |

## 7. 蓝屏了怎么办

1. 虚拟机自动重启/停在蓝屏
2. 调试器里会打印 `*** Fatal System Error` + `BugCheck ...`
3. 输入 `!analyze -v`，看 `MODULE_NAME` / `IMAGE_NAME`（通常是你的驱动）
4. 修代码 → 重新编译 → 部署
5. 如果虚拟机彻底起不来：**回滚快照**（见下）

回滚快照（Hyper-V 管理器 → 检查点 → 右键 → 应用），或管理员 PowerShell：

```powershell
Restore-VMSnapshot -VMName 'Win10-Pro-22H2' -Name 'clean-testsigning' -Confirm:$false
```

**养成习惯**：动注册表、装可疑驱动、做大改动之前先 `Checkpoint-VM`。

## 8. 常见问题

| 现象 | 原因 / 解法 |
|---|---|
| 装驱动报"Windows 无法验证此文件的数字签名" | testsigning 没生效。虚拟机里管理员 cmd 跑 `bcdedit /set testsigning on` 然后**重启**；确认虚拟机 Secure Boot 是关的（本环境已关） |
| `sc start` 报 577 / 0xC0000428 | 同上（签名/内核信任问题） |
| WinDbg 一直 `Waiting to reconnect` | ① 虚拟机没启动 ② 虚拟机没重启过（调试设置要重启才生效）③ 管道名写错 |
| 调试器连上但 `lm` 里没有我的驱动 | 符号路径没设、或 `.reload` 没跑 |
| Win10 里 `Invoke-Command -VMName` 报错 | 需要**管理员** PowerShell；虚拟机必须运行中；账户要有管理员权限 |
| 虚拟机没网 | Win10 用 `Default Switch` 自动 NAT；Win7 只有 Legacy 网卡，`ipconfig /renew` 一下 |
| 两台一起开特别卡 | 宿主只有 16 GB，**分开开** |
| `vmconnect` 打不开/没权限 | 用 `启动Win10.cmd` 的方式；或把账户加入 `Hyper-V Administrators` 后重新登录 |

## 9. 几个概念补充

**为什么 Win7 是 Gen1、Win10 是 Gen2？**
Win7 的官方 ISO 不能 UEFI 引导，只能 BIOS（Gen1）；Win10 用 UEFI（Gen2）+ 关 Secure Boot。

**为什么 Win7 没有 Aero？**
Hyper-V 的虚拟显卡只有基础显示，Win7 跑不出 Aero。需要 Aero/3D 就得换 VMware（本机条件不建议）。

**Win7 能测哪些驱动？**
应用层驱动、文件系统过滤驱动、内核模式软件驱动都没问题。
**别用它测存储栈/网卡栈**（Gen1 只有 IDE 控制器 + DEC21140 模拟网卡，和真实硬件路径差太远），这类测试用 Win10 虚拟机。

**激活状态**
Win7 零售版：30 天宽限期，之后黑桌面 + 每小时提示（不影响 testsigning/内核调试/离线补丁）。
Win10：未激活也能正常做驱动开发（只有水印和不能改个性化）。
如果要长期用，请用你自己的正版 MAK/KMS/零售密钥正常激活。
